## 2024-05-13 - [Avoid looping through world.loadedEntityList in Render events]
**Learning:** In Minecraft Forge mods, looping through `world.loadedEntityList` inside a `RenderWorldLastEvent` or any other render event executes the loop every single frame (up to 60+ times per second). This causes a significant performance bottleneck, especially on servers with many entities.
**Action:** Move logic that iterates over all entities to a `TickEvent.ClientTickEvent` (which runs at a fixed 20 ticks per second) or use more efficient methods like `world.getEntitiesWithinAABB` if checking within a specific area. Cache the needed entities or their data in variables that can simply be read and rendered in the render events.

This causes a significant performance bottleneck, especially on servers with many entities. Furthermore, when migrating logic to `TickEvent`, be very careful with early returns causing a cache memory leak or frozen state if the cache is not cleared.
**Action:** Move logic that iterates over all entities to a `TickEvent.ClientTickEvent` (which runs at a fixed 20 ticks per second) and cache needed entities. Ensure any early returns in `TickEvent` properly clear the cache and reset state variables to avoid memory leaks or ghost renders when changing dimensions or walking out of bounds.
